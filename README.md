# Project explaination

This project uses the Ames Housing dataset to build a compact regression workflow in a Jupyter notebook. The notebook covers:

- data loading and cleaning
- feature engineering
- model training and comparison
- model evaluation and visualization

## Dataset

The notebook expects the file [AmesHousing.csv](AmesHousing.csv) in the project root.

## Setup

1. Create and activate a Python environment.
2. Install the dependencies:

```bash
pip install -r requirements.txt
```

3. Open [Project.ipynb](Project.ipynb) in Jupyter and run the cells in order.

## What you will see

The notebook trains two regression models and compares them on the same data split. It also produces a scatter plot of actual vs predicted sale prices for the best-performing model.
